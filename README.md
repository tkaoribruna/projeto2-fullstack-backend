### Estrutura do Projeto

```text
projeto2-fullstack-backend/
├── backend/
│   ├── package.json
│   ├── .env.example              # Modelo das variáveis de ambiente
│   ├── database/                 # Scripts SQL, migrations e seed
│   └── src/
│       ├── server.js             # Configuração do servidor Express, middlewares e rotas
│       ├── routes/               # Definição das rotas e controladores
│       ├── models/               # Acesso ao banco de dados e regras de persistência
│       ├── middlewares/          # Autenticação JWT, validações e tratamento de erros
│       └── config/               # Configurações de conexão com o banco e JWT
│
└── README.md
```
